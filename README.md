# README



## Bar-seq analysis of suppressors in *Saccharomyces cerevisiae*



This repository contains the analysis pipeline for the paper on genetic suppressors in yeast. The pipeline covers raw sequencing read processing, barcode extraction, statistical analysis of differential abundance, GO term enrichment, and generation of figures.



### Reference sources



The reference barcode tables used in this pipeline are derived from:



- **Puddu et al. 2019** — [https://doi.org/10.1038/s41586-019-1164-9](https://doi.org/10.1038/s41586-019-1164-9)

- **SGDP (Saccharomyces Genome Deletion Project)**, producer — https://horizondiscovery.com/en/non-mammalian-research-tools/products/yeast-knockout-collection

## Pipeline overview



### 1. `barseq_analysis.R` — raw read processing



- Reads all `*.fastq.gz` files recursively from `seq_data/`.

- Extracts barcodes flanked by the adapter sequences `u1` / `u2` (and their reverse complements).

- Aggregates reads per barcode, computes mean quality.

- Matches barcodes against the merged reference (`ref/reference.txt`).

- Writes per-sample tables to `output/` and a summary to `data/sumtable_short.txt`.

- At the end, calls the Python scripts:

```
python3 src/barcode_dm.py

python3 src/barcode_blast.py

```



### 2. `barcode_dm.py` — barcode extraction from non-barcoded reads



- Takes `*_not_barcoded_raw_qual_count.csv` files.

- BLASTs reads against adapter sequences to recover barcodes that were missed by the initial regex-based extraction.

- Produces `*_output_dm_count.csv`, `*_not_matched_dm.csv`, and `data/sumdm.csv`.



### 3. `barcode_blast.py` — rescue of unmatched barcodes



- Takes `*_not_matched.csv` and `*_not_matched_dm.csv` files.

- BLASTs unmatched barcodes against the reference barcode database.

- Produces `*_blasted.csv`, `*_blasted_dm.csv`, and summary tables `data/sumblast.csv`, `data/sumblastdm.csv`.



### 4. `jcounts_sumtable.R` — count matrix and summary table



- Merges all per-sample count tables into a single wide count matrix (`data/jcounts_2026_article_suppr.csv`).

- Computes library quality metrics (yield, barcoded fraction, assigned fraction, etc.) and writes `data/sumtable.csv`.



### 5. `reads_analysis.R` — differential abundance analysis



- **Approach 1 (`f1`)**: DESeq2 on raw counts for pairwise comparisons.

- **Approach 2 (`f2`)**: custom z-test on log-transformed normalized counts.

- **Combined contrast (`norm_pd.txt`)**: difference-of-differences test comparing suppressor vs. normal background (pg−rg) − (pd−rd).

- Writes results to `data/filter/` and `data/norm_pd.txt`.



### 6. `GSEA.R` — GO enrichment analysis



- Runs `clusterProfiler::gseGO` on log2 fold changes for a set of pairwise comparisons.

- Applies GO term simplification (`simplify`, cutoff = 0.7).

- Outputs:

&#x20; - `data/GO_simple_unified.txt` — simplified results with BH-adjusted p-values.

&#x20; - `data/GO_no_correction_unified.txt` — full results without simplification.



### 7. `plots.R` — volcano plots and hit table



- Generates volcano plots for selected comparisons (`pg_pd`, `pg_rg`) with highlighted genes of interest.

- Writes `figures/<comparison>_volcano.svg`.

- Produces `data/stats_hits.txt` — table of significant hits with gene descriptions.



### 8. `summarising_plots.R` — quality control and summary figures



- Barplot of total reads and barcoded fraction per sample.

- Boxplots of yield, assigned fraction, and replicate correlation.

- ORF detection barplots (per replicate and consensus ≥ 2 of 3).

- Correlation of average YPGly counts with reference fitness (YKOC).

- Writes figures to `figures/`.

## How to run



1. Place raw FASTQ files in `seq_data/` (subdirectories allowed).

2. Ensure all reference tables are present in `ref/`.

3. Run the pipeline in order:



```bash

Rscript barseq_analysis.R          # raw processing + calls Python scripts

Rscript jcounts_sumtable.R         # build count matrix and summary

Rscript reads_analysis.R           # differential abundance

Rscript GSEA.R                     # GO enrichment

Rscript plots.R                    # volcano plots

Rscript summarising_plots.R        # QC and summary figures

```



> **Note:** `barseq_analysis.R` invokes `barcode_dm.py` and `barcode_blast.py` via `system()`. Make sure the working directory is set correctly and Python 3 is available.

## Notes



- The `convert_names()` function converts between systematic and standard yeast gene names using `ref/yeast_gene_names.txt`.

- Mating genes (`GO:0000747`) are excluded from differential abundance and volcano plots.

- Mitochondrial ORFs (from `ref/noMtDNA.csv`) are excluded where indicated.

- GO enrichment uses `keyType = "ENSEMBL"` with `org.Sc.sgd.db`.
